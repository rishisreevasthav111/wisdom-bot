# Database Schema: PostgreSQL with pgvector

This database schema powers the **Seniors' Wisdom** platform tips and semantic vector search using PostgreSQL and `pgvector`.

## Table Structure (`tips`)

| Column | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `id` | `UUID` | `gen_random_uuid()` | Unique tip identifier (Primary Key) |
| `author_id` | `UUID` | `gen_random_uuid()` | Senior contributor identifier |
| `text` | `TEXT` | `NOT NULL` | The full advice / tip text |
| `category` | `VARCHAR(50)` | `NOT NULL` | Category: `'course'`, `'professor'`, `'company'`, or `'general'` |
| `course_code` | `VARCHAR(100)` | `NULL` | Course code (e.g. `'OS'`, `'DBMS'`, `'CS301'`) |
| `course_name` | `VARCHAR(255)` | `NULL` | Full course title (e.g. `'Operating Systems'`) |
| `professor` | `VARCHAR(255)` | `NULL` | Professor name (if applicable) |
| `company` | `VARCHAR(255)` | `NULL` | Company name (if applicable) |
| `author_batch` | `VARCHAR(50)` | `NULL` | Senior graduating batch (e.g. `'2023 batch'`) |
| `anonymous` | `BOOLEAN` | `false` | Whether the tip was submitted anonymously |
| `embedding` | `vector(1536)` | `NULL` | 1536-dimensional semantic vector embedding |
| `created_at` | `TIMESTAMPTZ` | `now()` | Record creation timestamp |

> [!NOTE]
> Per specifications, `upvotes` and `status` columns are omitted from this schema.

---

## Embedding Strategy

To enable deep semantic search across questions like *"How to pass OS with Prof. Iyer"* or *"Amazon coding test tips"*, the `embedding` column stores vector representations generated by combining:
1. **Tip Advice Text** (`text`)
2. **Category** (`category`)
3. **Course Name & Code** (`course_name`, `course_code`)
4. **Professor** (`professor`)
5. **Company** (`company`)

### Standard Text Format to Embed

```
Category: course | Course: Operating Systems (OS) | Professor: Prof. Meera Iyer | Tip: Do all the xv6 labs, they're half the exam
```

---

## Semantic Vector Search

Search queries use cosine distance `<=>` indexed with HNSW:

```sql
SELECT
    id,
    text,
    category,
    course_code,
    professor,
    company,
    author_batch,
    anonymous,
    1 - (embedding <=> :query_embedding) AS similarity
FROM tips
WHERE 1 - (embedding <=> :query_embedding) > 0.4
ORDER BY embedding <=> :query_embedding
LIMIT 5;
```
